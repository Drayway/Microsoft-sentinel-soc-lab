# Public Repository Security Note

This portfolio repository is intentionally sanitized.

- Public IP addresses are redacted from screenshots used in the repository.
- Azure subscription IDs and user/profile identifiers are redacted where they appear.
- Passwords, secrets, tokens, private keys, and RDP files are not included.
- The lab used controlled authentication testing against infrastructure owned/authorized for the exercise.
- RDP exposure shown during the lab should not be treated as a production architecture recommendation.
